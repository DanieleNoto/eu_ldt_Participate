# Backend

## Develop

1. Mark [backend_py](./) directory as source
2. Install Python 3.12
3. Create Python 3.12 virtual environment
4. Install Make in Windows: https://gnuwin32.sourceforge.net/packages/make.htm
5. Set path make.exe to env variable PATH, default installation path: "C:\Program Files (x86)\GnuWin32\bin"
6. Install dependencies
   ```bash
   make install
   ```
7. Run backend in development mode
   ```bash
   make run-dev
   ```
